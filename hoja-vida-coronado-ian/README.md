# Hoja de Vida Web

* **Estudiante:** Ian Camilo Coronado Guachalla
* **Carrera:** Ingeniería de Sistemas
* **Descripción:** Sitio web interactivo que presenta mi curriculum vitae profesional, proyectos académicos y habilidades técnicas.

## Etiquetas HTML5 Utilizadas

* **Estructura semántica:** `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`
* **Texto:** `<h1>` a `<h3>`, `<p>`, `<strong>`, `<em>`, `<mark>`, `<small>`, `<time>`
* **Listas:** `<ul>`, `<ol>`, `<li>`
* **Tablas:** `<table>`, `<caption>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`
* **Multimedia:** `<figure>`, `<figcaption>`, `<img>`, `<audio>`, `<video>`
* **Formularios:** `<form>`, `<fieldset>`, `<legend>`, `<label>`, `<input>`, `<button>`

## Elementos de Accesibilidad Implementados

* **Atributo `alt`:** Textos descriptivos en imágenes dentro de `<figure>` y `<img>` para lectores de pantalla.
* **Etiquetas `<label>` vinculadas:** Asociación explícita con elementos de formulario (`<input>`, `<textarea>`, `<select>`).
* **Soporte de contraste y énfasis:** Uso de `<mark>` y `<strong>` para resaltar datos clave sin perder la estructura lógica.
* **Información temporal accesible:** Uso de `<time>` con atributos adecuados para lectura estandarizada de fechas.

## Instrucciones para Visualizar
1. Clona o descarga este repositorio.
2. Abre el archivo `curriculum.html` en cualquier navegador web moderno (Chrome, Edge, Firefox).
